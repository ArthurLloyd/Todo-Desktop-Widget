## 启动边缘修复依据与限制

Windows 无边框浮窗原先启用了系统阴影。底层窗口实现会为带阴影的无边框窗口处理额外边框尺寸；启动恢复桌面层级时，原生边框与 WebView 内容边界可能未同步刷新。点击固定按钮后恢复的现象与此一致。

本次关闭主浮窗及附加浮窗的原生阴影，在窗口模式恢复后调用 `SetWindowPos(... SWP_FRAMECHANGED ...)` 刷新边框，并使前端宽高跟随实际容器。该原因是基于代码与症状的定位，尚未在报告问题的朋友电脑上证明是唯一根因。

仍需实机复测：朋友电脑开机自启、Win + D、不同 Windows 显示缩放比例、多显示器；窄窗口及大字号的完整交互；真实账户新建清单后在 Microsoft To Do 中双向核对；macOS 构建及桌面行为。
